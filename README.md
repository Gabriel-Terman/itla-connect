# ITLA Connect

Red social académica desarrollada para la comunidad del Instituto Tecnológico de Las Américas (ITLA).

## Funcionalidades

- Registro de usuarios
- Inicio y cierre de sesión
- Publicaciones en tiempo real
- Perfil de usuario
- Feed dinámico
- Rutas protegidas

## Tecnologías

- React
- React Router
- Firebase Authentication
- Cloud Firestore
